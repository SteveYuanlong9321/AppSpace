统一体验，来源保持透明。

不把每家应用商店的原始界面塞进来。AppSpace 使用自己的列表与详情页，让搜索、应用信息和来源选择保持一致。

多来源搜索

把不同来源的结果放进同一个列表，并按照名称、包名和别名的匹配程度排序。

统一应用详情

在 AppSpace 自己的详情页中查看应用信息、截图与版本，并清楚地选择下载来源。

来源可辨识

同一个真实 Android 包名尽量合并在一起，但各来源的下载与版本信息仍独立保留。

Privacy & security

保持匿名，也要了解连接。

当前设计不要求创建 AppSpace 账号。搜索关键词、应用详情与下载请求会发送到相应的第三方来源，因此仍会产生必要的网络请求。

无需 AppSpace 账号

不需要注册 AppSpace 个人账号才能使用现有的搜索流程。

来源与权限透明

只从自己信任的来源安装应用；Shizuku 辅助安装需要用户自行配置与授权。

反馈与问题报告

报告问题时请去掉访问令牌、私人文件路径和其他敏感日志。
